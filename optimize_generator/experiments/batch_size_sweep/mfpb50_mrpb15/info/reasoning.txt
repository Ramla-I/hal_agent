---iwdg---
The datasheet provides explicit details for the IWDG registers.  
- **IWDG_KR** is at offset 0x00, 32 bits wide, with a 16‑bit KEY field (write‑only).  
- **IWDG_PR** is at offset 0x04, 32 bits wide, contains a 3‑bit prescaler field (PR[2:0]) and reserved upper bits. Access to PR is write‑protected: the software must first write the unlock code 0x5555 to IWDG_KR and the PVU status bit must be cleared. After a write, PVU becomes set while the update is ongoing.  
- **IWDG_RLR** is at offset 0x08, 32 bits wide, contains a 12‑bit reload field (RL[11:0]) and reserved upper bits. It is similarly write‑protected: the unlock code 0x5555 must be written to IWDG_KR and the RVU status bit must be cleared; RVU is set while the reload update is in progress.  
- **IWDG_SR** is at offset 0x0C, 32 bits wide, with two status bits: RVU (bit 1) and PVU (bit 0), both read‑only; all other bits are reserved.
