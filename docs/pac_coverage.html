Per device. A crate is built once per chip device, so each crate lists its devices indented beneath it: device N fired, M bug = N gates fired at compile time, M possible-bug (no visible check). The hal tag marks the family HAL; a device where the HAL will not build shows baseline fails right there, so a HAL that passes on some devices and fails on another (h7's stm32-hal2 fails only on stm32h7b3) shows both, per device. A HAL that could not be ported at all shows couldn't port. Each compiled crate is also marked by compile path: direct → PAC means its register access reaches the chip crate directly (the HALs themselves, plus HAL-less code like hubris, rustuino, anne-key); via hal means it reaches the PAC through that HAL. Scanned = source read statically only (weaker); the number is candidate sites, not compile-confirmed.
