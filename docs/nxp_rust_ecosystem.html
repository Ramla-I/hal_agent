Notes & caveats
  • SVD sources: canonical = github.com/nxp-mcuxpresso/mcux-soc-svd (.xml); legacy Kinetis (MK*, MKE04Z4, MKW41Z4) via community cmsis-svd/cmsis-svd-data; S32K via NXP CMSIS-PACK. No consumable single SVD for i.MX RT (raltool merges 12 per-device SVDs) or mcx-pac (chiptool from C headers in mcux-devices-mcx).
  • Dual-core → two SVDs: LPC55S69, MCXN947, K32L3A60 (M4+M0+), MIMXRT1176/1189. lpc55-pac / mcxn947-pac use core0 only; embassy nxp-pac uses both.
  • Shared RMs: S32K1XXRM → all 8 S32K; UM11147 → both RT600 (685S+633S, a User Manual); IMXRT1050RM → 1051/1052; IMXRT1060RM → 1061/1062 (1064 separate).
  • Two parallel MCX stacks: embassy-rs (nxp-pac→embassy-nxp/embassy-mcxa) and community mcx-rs (mcx-pac→mcx-hal/embassy-mcx). mcx-hal depends on mcx-pac, not mcxn947-pac.
  • ⚠ Soft spots: MCXA577 RM is login-gated (no public ID); mk66f18/k64 crate↔SVD links inferred. No NXP-official Rust HAL/PAC — NXP ships only SVDs.
  • Method: downstream = GitHub Cargo.toml dependent search (not exhaustive; crates.io reverse-deps not queried) — "none" = no public GitHub dependent found.
