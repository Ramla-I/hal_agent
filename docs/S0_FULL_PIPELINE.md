# S0 Full Pipeline (s0_run_full_analysis.py)

This file summarizes each step of the pipeline in `s0_run_full_analysis.py`, including the inputs and outputs for every stage.

## Setup and shared inputs

- **Inputs:** `config.DEVICE_NAME`, `config.GENERATOR_MODEL_NAME`, `config.RUN_ANALYZER`, `config.CONTEXT_RETRIEVAL_PARAMETERS`, `config.user_contexts`, repo root, device folders.
- **Outputs:** computed paths for `device_directory`, `svd_dir`, `agent_output_folder`, `results_directory`, `verified_datasheet_directory`.
- **Why it matters:** all downstream steps rely on these paths for reading inputs and writing results.

## Vector store / context setup

- **Inputs:** device PDF (when no vector store exists), `device_ctx.vs_id` from config.
- **Outputs:** `device_ctx.vs_id` and `device_ctx.file_id` saved to config; `context_retrieval_parameters.vs_id` updated.
- **Why it matters:** later steps retrieve context using the vector store id.

## Iterative loop: generator + coverage improver

This loop runs `config.COVERAGE_IMPROVER_ITERATIONS` times.

### Step (S1) Generator

- **Inputs:** `device_name`, `run_number`, `device_directory`, `agent_output_folder`, `model_name`, `context_retrieval_parameters`, `device_ctx.manufacturer`.
- **Outputs:** generator output files in `agent_output_folder`; `generator_truncated_at_any_register` flag.

### Step (S2) Coverage improver

- **Inputs:** 
  - `svd_path` (first `.svd` in `svd_dir`),
  - `agent_output_folder`,
  - `context_retrieval_parameters`,
  - `coverage_improver_model_name`,
  - `device_ctx.vs_id`.
- **Outputs:** 
  - `coverage_info` (coverage metrics),
  - `coverage_improver_output.json`,
  - updated `context_retrieval_parameters`,
  - **new run number** and **new output dirs** for the next iteration.

## Post-loop evaluation pipeline

### Step (S2) Compare agent output with SVD

- **Inputs:** each `*.svd` file in `svd_dir`, `agent_output_folder`.
- **Outputs:** per-SVD results under `results_directory/<svd_file_base>/` (including `register_diff.csv`, `field_diff.csv`, etc. as generated by the compare step).

### Step (S3) Analyzer agent (optional)

- **Inputs:** `register_diff.csv`, `model_name`, `svd_file_base`.
- **Outputs:** analyzer output JSON file in `agent_output_folder/analyzer_iteration/`, plus filtered `register_diff_analyzer.csv` that only includes rows referenced by the analyzer output.

### Step (S4) Generate diff table

- **Inputs:** `custom_results_dir`, `analyzer` flag.
- **Outputs:** diff tables in `custom_results_dir` (exact filenames depend on `generate_diff_table`).

### Step (S5) Compare diff with verified datasheet

- **Inputs:** `register_diff.csv` and `field_diff.csv`, plus verified datasheet CSV at `verified_datasheet/<device>_<svd>.csv`.
- **Outputs:** `register_diff_verified.csv` and `field_diff_verified.csv` in `custom_results_dir`.
