---AFIO_EVCR---
The datasheet section **7.4.1 Event control register (AFIO_EVCR)** directly provides the register name (AFIO_EVCR), its address offset (0x00), reset value (0x00000000) and that it is a 32‑bit word‑accessible register.  
The bit‑field table shows three usable fields:

* **EVOE** – bit 7, read‑write, enables the EVENTOUT signal.  
* **PORT[2:0]** – bits 6‑4, read‑write, selects the GPIO port (enumerated values are not listed in the excerpt).  
* **PIN[3:0]** – bits 3‑0, read‑write, selects the pin within the chosen port. The description gives the mapping 0→Px0, 1→Px1 … 15→Px15, which we list as enumerated values.

Bits 31‑8 are reserved and must stay at the reset value, so they are not included as subfields.

A note before the register description states that the AFIO clock must be enabled (via the RCC_APB2ENR register) before any read or write of AFIO_EVCR (or the related AFIO registers). This is captured as an access constraint.

No address calculation is required because the offset is given explicitly.
