---afio_evcr---
The datasheet section **7.4.1 Event control register (AFIO_EVCR)** describes the register that belongs to the AFIO peripheral.  
- It is named **AFIO_EVCR** (the abbreviation matches the peripheral name + register name).  
- The register is accessed as a 32‑bit word, therefore its size is 32 bits.  
- **Address offset** is **0x00** and **reset value** is **0x0000 0000**.  

The bit‑field table shows three writable fields (the remaining bits are reserved and must stay at the reset value):  

| Bits | Field | Description |
|------|-------|-------------|
| 7    | EVOE  | Event output enable – set/cleared by software; when set the EVENTOUT signal is connected to the I/O selected by PORT[2:0] and PIN[3:0]. |
| 6‑4  | PORT[2:0] | Port selection (A, B, C, D, E). Read‑write. |
| 3‑0  | PIN[3:0]  | Pin selection within the chosen port. Values 0‑F select Px0‑Px15 respectively. Read‑write. |

All three fields are **read‑write**. No enumerated values are defined beyond the binary encoding of the fields, but for **PIN[3:0]** the datasheet lists the mapping 0b0000 → Px0, 0b0001 → Px1, …, 0b1111 → Px15, which can be represented as enumerated values.

An important **access constraint** is mentioned: before any read or write of AFIO_EVCR (or AFIO_MAPR, AFIO_MAPR2, AFIO_EXTICRx) the AFIO peripheral clock must be enabled via the APB2 peripheral clock enable register (RCC_APB2ENR). This is a pre‑condition for any operation on the register.

No other ordering constraints or special write‑only/read‑only behavior are stated.

* **TIM2_REMAP[1:0]** (bits 9‑8) – TIM2 remap, read‑write, 2‑bit field.  
* **TIM1_REMAP[1:0]** (bits 7‑6) – TIM1 remap, read‑write, 2‑bit field.  
* **USART3_REMAP[1:0]** (bits 5‑4) – USART3 remap, read‑write, 2‑bit field.
